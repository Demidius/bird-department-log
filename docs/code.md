# Код: структура, договорённости, дизайн

Чистый HTML/CSS/JS без сборки и фреймворков. Supabase JS v2 с CDN (с `integrity`). Работающее приложение — папка **`v2/`** (телефон). Корневой `index.html` только перекидывает на `v2/`.

## Как устроено
- Обычные скрипты с общей глобальной областью; порядок — в `v2/index.html` и `SHELL` в `sw.js` (новый файл — в оба места + поднять `CACHE`).
- Весь экран перерисовывается `render()` из состояния `st`. Поля пишут в состояние по `data-in` (форма записи → `st.add`), `data-ein`/`data-etr` (правка карточки → `st.ed`); фокус и курсор сохраняются.
- Клики — один обработчик в `main.js` по атрибутам `data-*`. Новая функция = новый `data-атрибут` + ветка в обработчике (или свой `document.addEventListener('click')` в модуле-расширении).
- **Модуль-расширение** (как `breed.js`, `temp.js`): добавляет тип в `KINDS`, иконку в `BirdLog.icons`, и оборачивает функции-объявления (`genericForm`, `saveForm`, `recTitle`, `recDetails`, `placeCard`, `stepWhat`): `const _f = f; f = function () { …; return _f(); }`. Так новые функции не требуют правок больших файлов.
- Типы записей. В базе разрешены все типы (миграция `20261123_v2_records_comments.sql`), но новые виды записей пока пишутся как `type='obs'` + `f.k = вид` (`injury proc watch wend score mate diet env enr leave arrive dept temp`) — так их видит и старый код. Запись про место: `bird` = имя места + `f.place`. Свободная запись: `bird = '—'`. Значения выбора хранятся индексами списков `OPT`.
- Текущее место животного: последний перенос (`expo`, `f.to`) новее `collection.encl_at` побеждает (`anEncl`).
- Комментарии: таблица `comments` (ответы через `parent_id`); блок скрыт, если таблицы нет.
- Права: править запись — автор или админ (`canEditRec`); замки AI на полях — только админ.

## Договорённости
- Строки интерфейса — только `L('pl', 'ru', 'en')` прямо в коде, все три языка. HTML из данных — только через `esc()`.
- «Назад» телефона ведёт по экранам (History API в `main.js`: `go()`, `popstate`, окна закрываются первыми), на корне — вопрос о выходе. **Не ломать.**
- Без подписей-инструкций под полями. Ничего не выбрано заранее (кроме «Я» в «Кто переносил»).
- Тест: `python3 tests/test_newui.py /tmp/shots` — смотреть вывод и скриншоты (светлая/тёмная, ru/pl, ширина 390).

## Дизайн
- Design System «Журнал отдела птиц»: токены (цвета групп `--health --obs --breed --keep --dept` + `-soft`, `--accent`, `--fab`), шрифты Manrope (заголовки) + Inter (текст), классы `bl-*`.
- Группы записей с цветом: Здоровье, Наблюдение, Размножение, Содержание, Отдел. Две темы (Авто/Светлая/Тёмная).
- Телефон и компьютер: на окне ≥ 1000px — раскладка pc.js (три колонки); между телефоном и 1000px — колонка 520px по центру. Планшет — позже. В прототипе переключатель «Устройство: Телефон / Компьютер» (tools/proto_build.py).
- Владелец рисует экраны от руки и присылает фото — воспроизводить максимально близко.
