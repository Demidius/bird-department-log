# Код: структура, договорённости, дизайн

Чистый HTML/CSS/JS без сборки и фреймворков. Supabase JS v2 с CDN (с `integrity`).

## Файлы
```
index.html          разметка + базовые стили (<style> с CSS-переменными) + список скриптов
desktop.css         шторка загрузки, десктоп-раскладка, журнал, замки, переводы
i18n.js             словарь интерфейса DICT {ru, pl, en};  i18n-species.js — тексты карточки вида
pwa.js, sw.js       установка PWA и офлайн-кэш (network-first, cache:'no-cache', кэш 'zoo-log-vN')
js/*.js             приложение, 20 модулей — что где: docs/codemap.md
supabase/           схема (SCHEMA.md), миграции, код Edge Function admin-users
tools/codemap.py    пересобирает docs/codemap.md
tests/              браузерные тесты (Playwright + поддельный Supabase), tests/README.md
```

## Модули `js/`
- Обычные скрипты (не ES-модули) с общей глобальной областью: `const`/`function` верхнего уровня видны всем модулям.
- **Порядок важен**: он задан в `index.html` и повторён в `sw.js` (`SHELL`). Код, который выполняется сразу при загрузке (вызовы, `addEventListener`), может использовать только то, что объявлено в модулях выше. Внутри функций — что угодно.
- Новый модуль: файл `js/имя.js` (первая строка `// имя.js — назначение`) → `<script>` в `index.html` → `SHELL` в `sw.js` (+ поднять версию `CACHE`) → `python3 tools/codemap.py`. `tests/test_modules.py` проверяет, что всё совпадает.
- Задача про один экран — читай только его модуль + нужное из `core.js`/`data.js`. Найти функцию: `docs/codemap.md` или `grep -n "имя" js/*.js`.
- Не объявлять глобальные имена, совпадающие со свойствами `window` (`top`, `name`, `location`, `open`…).

## Договорённости
- Новые элементы интерфейса добавляются из JS (`add(selector, where, html)` в `js/screens.js`), `index.html` по возможности не трогать (кроме списка скриптов).
- Строки интерфейса — только `t('key')` и `DICT` во **всех трёх языках** (ru, pl, en). Склонения — массивы форм + `pw(n, key)`. Тексты новых функций — в `js/texts.js` (или `i18n.js`).
- HTML из данных — только через `esc()`. Иконки — набор SVG `I` / `ic(name)`, атрибут `data-ic`.
- Логины → псевдо-почта `<login>@zoo-log.invalid` (`LOGIN_DOMAIN`).
- Длинные списки (`select` > 6 пунктов) — своё окно с поиском (`openPick`, `#pick`, `js/pick.js`): клавиатура только по нажатию на поле поиска (не фокусировать автоматически). Поиск без регистра и диакритики; у видов — по всем названиям и латыни (`data-s`). «Назад»/Esc закрывают только окно.
- Выбор животного в записи — настоящий список `#fld-birdsel` (+ «Другое…» → `#fld-bird`). `datalist` не использовать (на телефонах не виден).
- Навигация — History API (`navStart`, `navState`, `setTab(v, fromBack)`, `popstate`, `js/ui.js`). «Назад» ведёт по экранам, на корневом — подтверждение выхода (`cf_exit`). **Не ломать.**
- Шторка загрузки: `body::before` в `desktop.css`, скрывается `body.ready`; `splash()` держит ≥ 700 мс; CSS-страховка 20 с. CSS и JS шторки публиковать одним коммитом.

## Языки
- По умолчанию польский, затем английский, затем русский (`LANG_ORDER = ['pl','en','ru']` — и порядок запасных переводов).
- Данные тоже в трёх языках (`names`, переводимые поля `info`).

## Дизайн
- Голос: спокойный практичный рабочий инструмент для смотрителей, без украшательства. Идея: бумажный журнал и планшет смотрителя в телефоне.
- Цвета только через CSS-переменные; светлая/тёмная тема через `light-dark()`:
  `--accent #1E6B4E/#66CDA1`, `--bg #E6EBE8/#0A0F0D`, `--app #F3F5F4/#111816`, `--card #FFFFFF/#18211D`, `--ink #15211C/#E8EEEB`, `--red #B42318`, `--amber #9A4A00`, `--blue #1D5FA8` (+ `-soft`/`-ink`).
- Шрифты: Manrope (заголовки 600–800), Inter (текст 400–700).
- Раскладка: одна колонка до 480px, липкие счётчики сверху, вкладки снизу, шторки снизу; десктоп — `desktop.css`. Крупные кнопки под одну руку; фокус и `aria-*` сохранять. Тема-цвет PWA `#1E6B4E`.
- Владелец рисует экраны от руки и присылает фото — воспроизводить максимально близко.

## Что умеет приложение (ключевые имена)
- Записи `records` (`ev_*`): наблюдение, смена экспозиции, лечение (назначение/подача/окончание), яйцо, насиживание, выклев, выход из гнезда, роды `birth`. Время необязательно: только дата `#fld-date`, время по кнопке (`#fld-time`); без времени — 12:00 и `f.nt = 1` (`recTime`, `when(ms, noTime)`).
- Предположительные события (`calItems` → `guess`): из `incub_days`/`fledge_days`/`gest_days`; в календаре значок в пунктирной рамке, в шторке дня — «Ожидается»; исчезают при настоящем событии.
- После «Выклёвывание»/«Роды» — предложение карточки потомства (`offerKid`).
- «Сейчас»: счётчики. Календарь: список/сетка; день кликабелен → шторка `#sheet-day` (`openDay`/`renderDay`), значки событий `.cdot.cic`, `calIc`.
- Коллекция: птицы и группы (`grp {m,f,u,j}`, «♂ 3 · ♀ 4 · ? 1 · молодые 2»), родители `parents` (любое число, можно группы), имя необязательно (создаётся из вида).
- Вольеры: иерархия, тип, площадь, вместимость. Справочник видов + карточка `info`. Фото у записей, птиц, видов, вольеров (bucket `journal-photos`, превью `*_t.jpg`); вертикальное фото вида — целиком (`fitPhoto`, `tall`).
- «Пропущенные данные» (`view-gaps`, `GAPS`, `renderGaps`, `openGap`). Журнал изменений (вкладки все/пользователи/AI/разработка). Пользователи (админ), экспорт CSV, офлайн-оболочка.
