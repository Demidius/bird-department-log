# Дизайн: сайт → макет → сайт

Владелец прорабатывает интерфейс в макете (артефакт Claude типа **Design**), потом изменения переносятся на сайт. Код не трогать, пока владелец не скажет «переносим на сайт».

## Где что
- Design System «Журнал отдела птиц» (токены, шрифты, компоненты `bl-*`, иконки): https://claude.ai/artifact/7m3Vz1LgqVYtJDKR6sm2sd — основа любого макета; новые компоненты добавлять туда же.
- **Макет приложения**: https://claude.ai/artifact/1s6S2pzy9EeJn3DL7HL72L — страница «Сайт сейчас · 23.11» (29 экранов, снятых с сайта: главные, карточки, добавление записи, формы, тёмная тема) и «Старый макет · 21.11» (история). Работать в нём; новые варианты — новыми артбордами рядом.
- Код сайта: `v2/` (см. `docs/code.md`), стили `v2/app.css`, иконки `v2/js/ds.js`.

## Этап 1. Сайт → макет (обновить снимки экранов)
1. `python3 tools/design_snap.py /tmp/canvas/project <css_url>` — открывает каждый экран приложения на тестовых данных и пишет его как артборд `.dc.html` (живая разметка сайта, стили — `v2/app.css`, загруженный в макет ассетом; `<css_url>` = его `/_blob/…`, при изменении `app.css` — загрузить заново). Список экранов — `S` в скрипте; новый экран — новая строка там.
2. Отправить файлы в макет (`publish_files`, mode patch). Если раскладка меняется — обновить `project/canvas.json` (секции — строками с заголовками, страница `site`), не трогая страницу `old` и правки владельца.
3. Дальше — правки по словам и рисункам владельца; каждое изменение — отдельный артборд «было / стало» или пометка, чтобы потом было видно, что переносить.
Снимки PNG для проверки — `python3 tests/test_newui.py /tmp/shots`.

## Этап 2. Макет → сайт (по команде владельца)
1. Прочитать макет, составить список отличий от сайта (экран → что меняется) и показать владельцу коротко.
2. Внести: стили — `v2/app.css` (токены не дублировать), новые функции — модулем-расширением `v2/js/<имя>.js` (см. `docs/code.md`), правки разметки — в нужном `v2/js/*.js`. Строки — в трёх языках.
3. Тест + снимки, сверить с артбордами; опубликовать одним коммитом; `select app.ai_dev('…')`; новые компоненты — в Design System; решение — строкой в `docs/decisions.md`.
