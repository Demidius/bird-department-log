# Браузерные тесты

Проверяют приложение в Chromium через Playwright с поддельным Supabase (`mock_supabase.js`). Настоящая база не трогается.

```
pip install playwright && python -m playwright install chromium   # или CHROME=/usr/bin/google-chrome
python3 tests/test_newui.py /tmp/shots                            # аргумент — папка для скриншотов
```

- `test_newui.py` — приложение `v2/` на данных `seed_v2.json` (виды, места, животные отдела + несколько придуманных записей): запись нескольким животным, назначение и подача, перенос по особям, место, свободная запись, поступление, комментарии, правка вида, календарь, «назад», ru/тёмная тема, без таблицы комментариев, только чтение, роды с родителями, температура вольера.
- Остальные `test_*.py` проверяют старую версию (`js/`, не используется) и будут удалены вместе с ней.

Тест печатает проверяемые значения и сохраняет скриншоты; падение = ошибка Playwright. Строка `ERRORS: ['An unknown error occurred when fetching the script.']` — service worker, которому в тесте не отдаётся `sw.js`; это не ошибка приложения.
