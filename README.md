# Dziennik działu ptaków · Журнал отдела птиц

PWA для документации отдела птиц зоопарка: записи событий, календарь, коллекция, места содержания, справочник видов.
Сайт: https://demidius.github.io/bird-department-log/

- `index.html`, `desktop.css`, `i18n*.js`, `js/*.js` — приложение (без сборки)
- `supabase/` — схема базы, миграции, Edge Function
- `docs/` — документация; для AI-агентов начинать с `AGENTS.md`
- `tests/` — браузерные тесты
