## Общение
- По-русски, **кратко** (владелец читает с телефона): что сделано, что не удалось/сомнительно, что проверить.
- **Не выдумывать данные** («Если не можешь найти данные, то не придумывай»). Нет источника — поле пустое, сообщить.
- «Сделай как оптимальнее» — выбирай сам и коротко объясни.

## Жёсткие правила
1. Никогда не запрашивать/хранить/выводить `service_role` ключ Supabase.
2. Роль `admin` — только кнопкой «claim first admin», никогда через SQL. Аккаунты — только Edge Function `admin-users`.
3. RLS и замки не ослаблять и не обходить. Данные — через `app.ai_*` (`docs/data.md`).
4. Строки интерфейса — в трёх языках (pl, en, ru). HTML из данных — через `esc()`.
5. Кнопка «назад» телефона ведёт по экранам, а не закрывает приложение — не ломать.
6. Код: тесты перед публикацией, связанные файлы — одним коммитом, после — `select app.ai_dev('…')`.

## Новая устойчивая инструкция владельца
Допиши одной строкой в `docs/decisions.md`; если она меняет правило — поправь и сам файл правил (этот или в `docs/`). Здесь держать только то, что нужно в каждой задаче.
